Deliveries

Record aggregate and waste deliveries directly in the app. All delivery records are stored digitally and can be reviewed, edited, and exported as a PDF.

On this page

  • Submitting a Waste Delivery

Submitting an Aggregate Delivery

Use this screen to record when aggregate materials are delivered to a job. A single record can include multiple material line items — for example, if one load contains several different materials.

  1. From the main menu, tap Deliveries → Aggregates.
  2. Confirm the date and time of the delivery.
  3. Select the Collected From site — the quarry or supplier the load came from.
  4. Select the Delivered To job site — the destination receiving the aggregate. Use Find Nearest Job or Find Last Job to fill either site field in quickly (see below).
  5. In the Material Details section, select the material type and enter the quantity for each line item.
  6. To add a second material to the same delivery, tap + Add Material. You can add up to 10 material lines per record.
  7. To remove a material line, tap the × icon next to it.
  8. Optionally, tap Take Photo to photograph the delivery ticket and attach it to the record (tap Change Photo to replace it).
  9. Review the Confirm Delivery summary and tap Confirm & Save.

Finding the Collected From / Delivered To site

Two shortcuts help you fill in either site field without typing:

Find Nearest Job
Uses GPS to find the closest active project. The button relabels to Find Next — tap it again to cycle through other nearby sites if needed.
Find Last Job
Opens a list of recent projects for quick selection.
✅

Record each delivery as it arrives on site, rather than at the end of the day. This ensures accurate quantities and delivery times.

Submitting a Waste Delivery

A waste delivery record is created each time a waste load leaves the site. Each record covers a single waste type. The app captures a signature from the waste facility receiving the load.

  1. From the main menu, tap Deliveries → Waste.
  2. Confirm the date and time.
  3. In the Collection section, select the job or location the waste is being removed from. Use Find Nearest Job or Find Last Job to fill this in quickly.
  4. Select the waste material from the list. The EWC code field will be filled in automatically based on the material you select — check it and adjust if needed.
  5. Enter the quantity and unit.
  6. If the waste is classified as hazardous, switch on the Hazardous toggle. You will then be required to enter a waste description.
  7. If reinstatement material is being removed, tick the Reinstatement checkbox.
  8. In the Delivery section, select the waste facility where the load is being taken. The facility's EPA licence number is shown for reference.

Receiver (facility) signature

If the waste facility requires a signature from their staff to confirm receipt, you can capture it in the app:

  1. At the waste facility, tap Capture Signature.
  2. Hand your phone to the facility operative.
  3. They sign directly on the screen using their finger.
  4. Tap Save to store it (or Clear to redo it). The button relabels to Signature Captured once done.
  1. Review all details and tap Save Delivery.
⚠️

Each waste delivery record covers a single waste type. If you are moving different waste types in separate loads, create a separate record for each.

My Deliveries — Viewing, Editing, Deleting & PDF

My Deliveries is a complete history of all delivery records you have submitted. You can filter the list, edit or delete records, and export any delivery as a PDF.

  1. From the main menu, tap Deliveries → My Deliveries.
  2. Your deliveries are shown for the currently selected week. Use the arrow buttons to move to the previous or next week.

Filtering and searching

Within the selected week, use the column header filters and quick filter bar to narrow down the list:

  • Type — filter by Aggregate or Waste
  • Date — tick specific dates from that week's checkbox filter
  • Collected From / Delivered To — filter by site, using each column's checkbox filter
  • Material — filter by material, using the column's checkbox filter

Editing a delivery

Tap the Edit (pencil) icon directly on a delivery's row to open it pre-filled for update. Change the relevant fields and save.

Deleting a delivery

  1. Tap the Delete (bin) icon on the delivery's row.
  2. Confirm the deletion in the Delete Delivery prompt that appears.
⚠️

Deletion is permanent. Only delete a record if it was entered in error.

Exporting to PDF

You can export one or more delivery records as a single combined PDF — useful for providing a paper copy to a client or waste facility.

  1. Tick the PDF checkbox on each delivery row you want to include (at least one).
  2. Tap the PDF icon in the top toolbar to generate the document.
  3. The PDF is built for the selected deliveries and you can save it, print it, or share it via email or messaging apps.
✅

PDF exports include all delivery details, both signatures (where captured), and a timestamp. They are suitable for use as waste transfer notes or delivery dockets.
