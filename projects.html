Projects

The Projects section lets you create a new project directly in the app, and quickly look up details for an existing one. Access is role-controlled — this section only appears for office/admin users who have been given the Projects permission.

Accessing Projects

From the Main Menu, tap Projects to expand the section:

Menu item What it does
Create Project Set up a brand new project
Get Project Description Look up and copy a project's full description, e.g. for naming a Dropbox folder
Get WhatsApp Message Look up a project and get a ready-formatted summary to paste into WhatsApp
ℹ️

Creating a project here is intended for the occasions the person who normally sets up projects isn't available — evenings, weekends, shutdowns — so a job can be opened without waiting. It's not a replacement for the usual process.

Creating a Project

Tap Projects → Create Project and work down the form:

  1. Select the Contract. Once chosen, its description, type, and job number prefix are shown underneath for confirmation.
  2. Select the Client / Region — this list is filtered to match the Contract you picked.
  3. Select the Client's Representative — filtered by both Contract and Region.
  4. Client Name fills in automatically once a Representative is selected.
✅

These four fields only offer real, existing clients and contracts — there's no free typing here, so there's no risk of a typo creating a mismatched or unmatched client record.

Setting the Location

You have three ways to set the project's GPS coordinates:

  • Use My GPS Location — uses your device's current position.
  • Pick / Verify Location on Map — opens a map you can tap or drag a marker on to set the exact spot, with a "Use current location" shortcut inside.
  • Type the Latitude / Longitude values directly, if you already know them.

Once coordinates are set, tap Look Up County/Town to auto-fill those two fields — they're editable afterwards if the lookup isn't quite right. County, Town, and Address are automatically capitalised as you type (first letter of each word capital, rest lower case), and any trailing spaces are trimmed automatically when you move to the next field — this matters because these values are later used to name folders on the server, and a stray trailing space causes problems there.

Address is optional — use it for a street address or a short description to help identify the location (e.g. "WWTP").

Finally, select the Type of Work (filtered by the chosen Contract) and enter a Description of Work — both required.

Optional fields

  • ROL Required and Road Closure checkboxes.
  • Parent Job Number — search for and link an existing project as the parent. Type in the search box, then pick from the matching results; the parent's details are shown read-only once selected, with an option to remove the link.

Preview & Create

Tap Preview & Create Project to see a summary of exactly what will be created — including the generated project number and the Folder Description — before anything is saved. Check it over, then tap Create to confirm, or Cancel to go back and make changes.

After a Project is Created

The screen shows the new project number and its Folder Description, with a copy button so you can paste it straight into Dropbox (or anywhere else) to name the project folder.

ℹ️

A project created here doesn't appear in every system immediately — it needs to be picked up by a background sync step before it's fully available everywhere the usual project list is used. This is normally quick, but don't be surprised if it takes a little while to show up outside the app.

Get Project Description

A quick lookup tool for finding a project's full description text — handy any time you need to name something after a project (e.g. a Dropbox folder) without hunting through the full project list.

  1. Tap Projects → Get Project Description.
  2. Type a project number or name into the search box.
  3. Select the matching project from the dropdown.
  4. Tap the copy icon next to the description to copy it to your clipboard.

Get WhatsApp Message

Generates a ready-formatted project summary — Project Name, Client Name, Description of Work, and a Google Maps GPS link — for pasting into a WhatsApp chat.

  1. Tap Projects → Get WhatsApp Message.
  2. Type a project number or name into the search box.
  3. Select the matching project from the dropdown.
  4. Tap the copy icon next to the message to copy it, then paste it into WhatsApp.
